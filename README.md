# Виджет банковских операций
## Цель проекта
Цель проекта — разработка бэкенд-части виджета для личного кабинета клиента банка.
Виджет показывает несколько последних успешных банковских операций клиента.
## Функции проекта
`mask_account_card` - объединяет обработку номеров банковских карт и счетов в зависимости от типа входных данных.
`get_mask_card_number` - маскирует номер банковской карты, оставляя видимыми первые шесть и последние четыре символа.
`get_mask_account` - маскирует номер банковского счета, оставляя видимыми последние четыре цифры.
`filter_by_state` - фильтрует список словарей по значению ключа 'state'.
`sort_by_date` - принимает и возвращает список отсортированный по дате.
`get_date` - возвращает дату в формате ДД.ММ.ГГГГ.

## Генераторы
`filter_by_currency` - фильтрует транзакции по заданному коду валюты.
`transaction_descriptions` - возвращает описания транзакций по одному с помощью генератора.
`card_number_generator` - генерирует номера банковских карт в формате XXXX XXXX XXXX XXXX в заданном диапазоне.
## Логирование
В модуле masks.py настроено логирование операций маскировки банковских карт и счетов. Сообщения об успешном выполнении записываются в файл logs/masks.log с указанием времени и уровня сообщения.

## Поиск и обработка банковских операций
`process_bank_search(data, search)` — выполняет поиск банковских операций по строке в описании или категрии. Поиск не зависит от регистра букв.
`process_bank_operations(data, categories)` — подсчитывает количество операций по заданным категориям описания.

## Запуск программы
Запустите `main.py`. Программа позволяет выбрать формат входного файла (JSON, CSV или XLSX), указать статус операций, отсортировать операции по дате, отфильтровать операции в рублях и выполнить поиск по описанию.
Если после применения фильтров операции не найдены, программа выводит соответствующее сообщение.
## Чтение файлов CSV и Excel
Для чтения финансовых операций из файлов CSV и Excel используется модуль file_readers.py.

`read_csv_file(file_path)` — читает CSV-файл и возвращает список словарей с данными о финансовых операциях.

`read_excel_file(file_path)` — читает Excel-файл и возвращает список словарей с данными о финансовых операциях.

Для обработки файлов используется библиотека pandas.
## Декоратор log
В модуле decorators.py реализован декоратор log, который записывает результат выполнения функции или информацию о возникшей ошибке. Логирование выполняется в консоль, если имя файла не указано, или в файл, если передан параметр filename.

## Работа с внешним API
Модуль external_api.py содержит функцию `convert_currency(transaction)`, которая конвертирует сумму банковской операции в рубли с помощью внешнего API курсов валют. Если валюта операции — RUB, сумма возвращается без конвертации.

Для работы с API используется ключ API_KEY, загружаемый из переменных окружения.
## Пример работы программы
Программа позволяет выбрать формат входного файла (JSON, CSV или XLSX), задать статус операций, отсортировать их по дате, отфильтровать рублёвые операции и выполнить поиск по описанию.
После ввода параметров программа выводит список операций, соответствующих выбранным условиям. Если подходящих операций нет, выводится сообщение:

Операции не найдены.

## Главная страница банковского виджета
Модуль views.py формирует JSON-ответ с данными для главной страницы банковского приложения.

Основная функция `get_main_page_data(date_time)` принимает дату и время в формате YYYY-MM-DD HH:MM:SS и возвращает JSON со следующими данными:

• Приветствие в зависимости от времени суток.

• Последние четыре цифры номера каждой карты, общая сумма расходов и кешбэк (1 рубль на каждые 100 рублей расходов).

• Топ-5 транзакций по сумме платежа.

• Курсы валют, указанных в user_settings.json.

• Цены акций, указанных в user_settings.json.

Для анализа используются операции с начала месяца по переданную дату.
## Внешние API: курсы валют и цены акций
Модуль external_api.py содержит функции:

• convert_currency(transaction) — конвертирует сумму операции в рубли.

• get_currency_rates(currencies) — получает курсы валют, указанных в пользовательских настройках.

• get_stock_prices(stocks) — получает цены акций по указанным тикерам.
Список валют и акций задаётся в файле user_settings.json. Для HTTP-запросов используется библиотека requests. При ошибках API некорректные или недоступные данные пропускаются, а обработка остальных элементов продолжается.

Для работы с API, требующим ключ, используется переменная окружения API_KEY. Секретные ключи не следует публиковать в репозитории.
## Простой поиск банковских операций
В модуле services.py реализована функция simple_search(transactions, query), которая возвращает JSON со всеми транзакциями, содержащими поисковую строку в описании или категории.

Поиск выполняется без учёта регистра и поддерживает поиск по части слова.
## Отчёты
В модуле reports.py реализована функция spending_by_category(transactions, category, date=None), которая возвращает расходы по указанной категории за последние три месяца относительно заданной даты. Если дата не указана, используется текущая дата.

Декоратор report_to_file сохраняет результат выполнения функции-отчёта в файл. Можно использовать имя файла по умолчанию или передать собственное имя.
