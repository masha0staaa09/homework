# Виджет банковских операций
## Цель проекта
**Цель проекта** — разработка бэкенд-части виджета для личного кабинета клиента банка. Виджет показывает несколько *последних успешных банковских операций* клиента.
## Функции проекта
- `filter_by_state` - фильтрует операции по статусу.
- `sort_by_date` - сортирует операции по дате.
- `get_mask_card_number` - маскирует номера банковской карты.
- `get_mask_account` - маскирует номера банковского счета.
- `mask_account_card` - обрабатывает информацию как о картах, так и о счетах.
- `get_date` - возвращает дату в фотмате ДД.ММ.ГГГГ.
